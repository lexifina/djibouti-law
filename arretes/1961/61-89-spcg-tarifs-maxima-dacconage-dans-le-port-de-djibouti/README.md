# Arrêté n° 61/89/SPCG fixant les tarifs maxima d’acconage dans le Port de Djibouti

Arrêté · Journal officiel de la République de Djibouti, n° 8 du 31/08/1961 · <https://www.journalofficiel.dj/texte-juridique/arrete-n-61-89-spcg-fixant-les-tarifs-maxima-dacconage-dans-le-port-de-djibouti/>

En vigueur : 1961-08-31 (date du Journal officiel qui le publie).

Vu l'ordonnance organique du 18 septembre 1844 rendue applicable au Territoire par décret du 18 juin 1884 ;
