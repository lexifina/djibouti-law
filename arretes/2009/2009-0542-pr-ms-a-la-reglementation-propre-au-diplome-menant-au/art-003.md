# Article 3
– Le programme comprend 7 modules
– Le module 1 : Introduction aux sciences infirmières et soins infirmiers. Ce module est reparti en 6 sous modules ;
– Le module 2 : Sciences fondamentales. Ce module est reparti en 6 sous module ;
– Le module 3 : Soins infirmiers et pathologie. Ce module est reparti en 2 sous modules ;
– Le module 4 : Sciences humaines et culture générale. Ce module est reparti en 8 sous modules ;
– Le module 5 : Santé publique. Ce module est reparti en 9 sous modules ;
– Le module 6 : Gestion. Ce module est reparti en 5 sous modules ;
– Le module 7 : Méthodologie de la recherche en sois infirmiers. Ce module est réparti en 3 sous modules.
