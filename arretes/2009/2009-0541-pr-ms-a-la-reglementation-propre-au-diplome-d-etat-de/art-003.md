# Article 3
Le programme comprend 8 modules :
– Le module 1 : Profession/éthique et bioéthique/législation.. Ce – – module est reparti en 3 sous modules ;
– Le module 2 : Sciences fondamentales.et pathologies générales Ce module est reparti en 4 sous module.
– Le module 3 : Soins infirmiers/anesthésie/réa. Ce module est reparti en 2 sous modules ;
– Le module 4 : Sciences humaines et Sociales. Ce module est reparti en 6 sous modules ;
– Le module 5 : Santé publique. Ce module est reparti en 5 sous modules ;
– Le module 6 : Obstétrique normal et pathologique. Ce module est reparti en 3 sous modules.
– Le module 7 : Régulation de naissances IST/SIDA/Gynécologie. Ce module est réparti en 3 sous modules.
– Le module 8: Santé du nouveau-né et de l’enfant moins d’1 ans. Ce module est réparti en 3 sous modules.
