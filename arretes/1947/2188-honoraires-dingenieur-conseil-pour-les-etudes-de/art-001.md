# Art. 1er
— Les honorai res d’ingénieur-conseil pour les études de béton armé sont fixées comme suit :
a) Pour un bâtiment isolé ou prototype 5 p. 10) (cinq pour cent) du montant des travaux de béton armé;
b) Pour les répétitions d’ouvrages on appliquera la formule suivante :
Hn= 0.5+ H – 0.5/ n =
H n étant le taux des honoraires pour l’ouvrage de rang n et H, le taux des honoraires pour le prototype.
