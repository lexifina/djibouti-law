# Art. 1er
— L’article 21.12.03 du Code général des Impôts est complété par l’adjonction d’un paragraphe 7° libellé ainsi qu’il suit :
7° Les matériels suivants, lorsqu’ils sont destinés à des associations exerçant leur activité sans but lucratif :
— les aéronefs ;
— les moteurs de ces aéronefs :
— les matériels d’équipements des aéronefs et des moteurs
d’aéronefs ;
— les parachutes et les instruments de contrôle de chute libre ;
— les pièces de rechange concernant les matériels énumérés ci-dessus. »
