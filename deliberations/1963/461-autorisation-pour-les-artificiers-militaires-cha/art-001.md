# Art. 1er
— L’Artificier Militaire contrôlant occasionnellement les opérations de chargement, déchargement ou de transit d’explosifs ou munitions dans le Port de Djibouti est autorisé à présenter aux destinataires du secteur privé, pour le compte de qui ces opérations sont effectuées, une note de rétributin basée sur les redevances fixes horaires suivantes :
— 1° De jour (jours ouvrables) : 200 francs de l’heure ;
— 2° Hors les heures ouvrables, dimanches, les jours fériés
et de nuit : 500 francs de l’heure.
