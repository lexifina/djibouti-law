# Art. L.2241-102
L'intermédiaire de commerce est un commerçant qui doit remplir les conditions pour exercer le commerce.
Les conditions d'accès aux professions d'intermédiaires de commerce spécialisées peuvent, en outre, être complétées par des conditions particulières visées au présent code.
L'intermédiaire peut être une personne physique ou une personne morale.
