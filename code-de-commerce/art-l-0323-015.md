# Art. L.323-15
Le rapport sur la gestion du groupe expose la situation de l'ensemble constitué par les entreprises comprises dans la consolidation, son évolution prévisible, les événements importants survenus entre la date de clôture de l'exercice de consolidation et la date à laquelle les comptes consolidés sont établis ainsi que ses activités. Ce rapport peut être inclus dans le rapport de gestion.
