# Art. L.2282-514
Les créanciers titulaires de privilèges spéciaux ont, sur les meubles qui leur sont affectés comme assiette par la loi, un droit de préférence qu'ils exercent, après saisie, selon les dispositions prévues par l'article L.2283-2 ci-après.
Le droit de préférence s'exerce aussi, par subrogation, sur l'indemnité d'assurance du meuble qui a péri ou disparu, tant qu'elle n'est pas payée.
