# Art. L.2271-141
Le chèque émis et payable à Djibouti doit être présenté au paiement dans le délai de huit jours.
Le chèque émis hors de Djibouti et payable à Djibouti doit être présenté dans un délai de quarante jours.
Le point de départ des délais indiqués ci-dessus est le jour porté sur le chèque comme date d'émission.
