# Art. L.4400-6
L'appel, lorsqu'il est recevable pour une décision rendue en matière de redressement judiciaire ou de liquidation judiciaire ou de faillite personnelle est formé dans le délai de quinze jours à compter du prononcé de la décision.
L'appel est jugé, sur pièces, par la juridiction d'appel, dans le mois. La décision d'appel est exécutoire sur minute.
