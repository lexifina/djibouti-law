# Art. L.2282-328
Le créancier inscrit, une fois accomplies les formalités d'inscription, doit notifier au bailleur de l'immeuble dans lequel est exploité le fonds le bordereau d'inscription ou celui de la modification de l'inscription initiale. A défaut, le créancier nanti ne peut se prévaloir des dispositions de l'article L.2282-334 ci-après.
