# Art. L.2282-511
Les privilèges généraux mobiliers confèrent un droit de préférence sur les meubles, exercé par leurs titulaires selon les dispositions prévues par les articles L.2283-2 ci-après.
Les textes spéciaux créant des privilèges généraux doivent préciser le rang de ceux-ci en le déterminant par rapport aux dispositions de l'article L.2282-512 ci- après. A défaut, le rang de ces privilèges est le dernier de celui établi par l'article L.2282-512 ci-après.
