# Art. L.2282-337
L'inscription garantit, au même rang que le principal, deux années d'intérêt.
Le créancier nanti et le vendeur privilégié ont, sur le fonds, un droit de préférence qu'ils exercent selon les dispositions de l'article L.2283-2 ci-après.
