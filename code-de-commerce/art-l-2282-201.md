# Art. L.2282-201
Le gage commercial est le contrat par lequel un bien meuble est remis au créancier ou à un tiers convenu entre les parties pour garantir le paiement d'une dette.
Le gage constitué soit par un commerçant soit par une personne non commerçante pour un acte de commerce constitue un gage commercial.
