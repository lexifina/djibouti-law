# Art. L.2254-7
Le concessionnaire peut être tenu d'acquérir une quantité de produits déterminée par une clause de quota ou une clause de minima.
L'objectif, qu'il soit indicatif ou impératif, doit être fixé de manière raisonnable, sans arbitraire ni discrimination.
La même exigence concerne le prix auquel le concessionnaire doit acquérir les produits.
