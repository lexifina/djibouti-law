# Art. L.342-6
Est puni d'une amende de 2.000.000 FDJ le fait, pour le président, les administrateurs ou les directeurs généraux d'une société anonyme, de ne pas, pour chaque exercice, dresser l'inventaire et établir des comptes annuels et un rapport de gestion.
