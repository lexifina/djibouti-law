# Art. L.318-95
Lors de l'émission de valeurs mobilières représentatives de créances sur la société émettrice, y compris celles donnant le droit de souscrire ou d'acquérir une valeur mobilière, il peut être stipulé que ces valeurs mobilières ne seront remboursées qu'après désintéressement des autres créanciers.
Dans ces catégories de valeurs mobilières, il peut être également stipulé un ordre de priorité des paiements.
