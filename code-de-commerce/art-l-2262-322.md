# Art. L.2262-322
Interdiction d'invoquer le secret bancaire Le secret bancaire ou professionnel ne peut être invoqué pour refuser de fournir les informations prévues par l'article L.2262-220 ou requises dans le cadre d'une enquête portant sur des faits de blanchiment ordonnée par ou effectuée sous le contrôle d'une autorité judiciaire.
