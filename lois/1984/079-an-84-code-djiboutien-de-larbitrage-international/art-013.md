# Article 13
– Les arbitres statueront comme amiables compositeurs si les parties leur en ont donné le pouvoir.
Les pouvoirs d’amiables compositeurs donnent aux arbitres la faculté d’écarter les solutions du droit applicable selon l’article 12, s’ils estiment leurs conséquences inéquitables. Dans tous les cas, les arbitres amiables compositeurs doivent respecter l’ordre public international.
