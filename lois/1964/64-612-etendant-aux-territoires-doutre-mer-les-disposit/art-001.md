# Art. 1er
— Les dispositions prévues aux articles 104 à 108 du Code pénal tel qu’il est appliqué dans les départements métrovolitains et dans les départements d’outre-mer sont étendues aux territoires d’outre-mer.
Ces dispositions deviennent les articles 108-1 à 108-5 du Code pénal applicable dans les territoires d’outre-mer et constituent le chapitre ler bis « Des ttfôupements > du titre 1e du livre III Oudit Code.
