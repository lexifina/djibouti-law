# Article 11
La titularisation
À l’expiration d’une période d’un an dans le service d’affectation, la titularisation du stagiaire intervient si l’intéressé a donné satisfaction sur le plan professionnel.
Dans le cas contraire, le stagiaire est révoqué. Il peut cependant, dans certaines circonstances, bénéficier d’une prorogation de stage d’une année.
