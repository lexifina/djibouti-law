# Article 2
Un agent est une personne titulaire, au service d’une administration publique, chargée dans l’exécution d’une mission des services publics.
En général, on distingue différentes catégories : les fonctionnaires, les agents conventionnés, les auxiliaires et enfin, les temporaires.
