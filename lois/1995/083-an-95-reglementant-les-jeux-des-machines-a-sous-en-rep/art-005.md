# Art. 5
‑ Les personnes morales peuvent être déclarées pénalement responsables dans les conditions prévues par l’article 21 du Code pénal, les infractions à la présente loi.
‑ Les peines encourues par les personnes morales sont :
1. ‑ L’amende suivant les modalités prévues par l’article 46 au Code pénal.
2. ‑ Les peines mentionnés à l’article 47 du Code pénal.
