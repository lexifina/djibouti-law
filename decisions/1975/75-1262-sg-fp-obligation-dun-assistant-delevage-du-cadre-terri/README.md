# Décision n° 75-1262/SG/FP portant obligation d’un assistant d’élevage du cadre territorial de régler toutes les dépenses résultant de l’accident qu’il a causé.

| [texte.md](texte.md) |  Mohamed Moussa Chehem assistant d’Elevage de 2e classe, 1er échelon du cadre territorial du service de l’Elevage qui a commis un accident pendant les heures de service avec un véhicule administratif est tenu de supporter toutes les dépenses et dommages résultant de l’accident qu’il a causé. |
