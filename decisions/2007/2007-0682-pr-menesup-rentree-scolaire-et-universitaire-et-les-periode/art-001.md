# Article 1
La rentrée scolaire 2007-2008 s’effectuera selon le calendrier suivant :
* Le lundi 03 septembre 2007 pour l’enseignement de base ;
* Le mercredi 05 septembre 2007 pour le CFPEN ;
* Le lundi 10 septembre 2007 pour les établissements de l’enseignement moyen et secondaire ;
