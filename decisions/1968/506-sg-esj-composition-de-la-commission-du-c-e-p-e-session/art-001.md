# Art. 1er
— Des centres d’examen du C-E-P.E. seront ouverts le mercredi 29 mai 1968 à 7 heures précises à:
Djibouti: Ecole du boulevard de la République pour les candidats de ce district ;
Ecole de Boulaos pour les candidates de ce district ;
Ali-Sabieh: Ecole d’Ali-Sabieh pour les candidats de ce Cercle.
Dikhil : Ecole de Dikhil pour les candidats de ce Cercle:
Tadjourah: Ecole de Tadjourah pour les candidats de ce Cercle.
Obock : Ecole d’Obock pour les candidats de ce Cercle.
