# Art. 1er
— Une allocation de sept cent cinquante francs (750 francs) une fois payée, pour premiers frais d’installation, est attribuée à chacun des agents contractuels malgaches débarqués à Djibouti le 26 mars 1946 dont les noms suivent :
Andrianarifetra (Ch.-G.) ;
Ranaïvo (Norbert) ;
Rabetokotany (Laurent) ;
Rakotondrasoa ;
Ranaivoson.
