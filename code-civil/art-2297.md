# Article 2297
Le privilège est un droit que la qualité de la créance donne à un créancier d'être préféré aux autres créanciers, même hypothécaires. Il peut être sur les meubles ou sur les immeubles.
Entre les créanciers privilégiés, la préférence se règle par les différentes qualités des privilèges.
Lorsqu'ils sont dans le même rang, les créanciers privilégiés sont payés par concurrence.
