# Article 2178
Il est spécial quand il est donné pour une affaire ou certaines affaires seulement ; il est général quand il est donné pour toutes les affaires du mandant.
Lorsqu'il est général, le mandat ne permet que les actes d'administration.
S'il s'agit d'aliéner ou hypothéquer, ou de quelque autre acte de propriété, le mandat doit être exprès.
