# Article 2303
Le nantissement est un contrat par lequel un débiteur remet une chose à son créancier pour sûreté de la dette.
Les nantissements sans dépossession qui portent sur : les droits d'associés et valeurs mobilières ; le fonds de commerce ; le matériel professionnel ; les stocks de matières premières et de marchandises, sont régis par les dispositions du code de commerce.
Le nantissement d'une chose mobilière s'appelle gage. Celui d'une chose immobilière s'appelle gage immobilier.
