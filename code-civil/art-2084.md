# Article 2084
L'article 952 est applicable aux créanciers de l'indivision, ainsi qu'aux créanciers personnels des indivisaires.
Toutefois, ces derniers ne peuvent provoquer le partage que dans les cas où leur débiteur pourrait lui- même le provoquer. Dans les autres cas, ils peuvent poursuivre la saisie et la vente de la quote-part de leur débiteur dans l'indivision en suivant les formes prévues par le code de procédure civile. Les dispositions de l'article 2081 sont alors applicables.
