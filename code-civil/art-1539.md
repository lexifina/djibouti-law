# Article 1539
Le débiteur de plusieurs dettes peut indiquer, lorsqu'il paie, celle qu'il entend acquitter.
À défaut d'indication par le débiteur, l'imputation a lieu comme suit : d'abord sur les dettes échues ;
parmi celles-ci, sur les dettes que le débiteur avait le plus d'intérêt d'acquitter. À égalité d'intérêt, l'imputation se fait sur la plus ancienne ; toutes choses égales, elle se fait proportionnellement.
