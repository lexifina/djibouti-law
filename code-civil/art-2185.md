# Article 2185
Le mandataire répond de celui qu'il s'est substitué dans la gestion :
1° quand il n'a pas reçu le pouvoir de se substituer quelqu'un ;
2° quand ce pouvoir lui a été conféré sans désignation d'une personne, mais que celle qu'il a choisie était notoirement incapable ou insolvable.
Dans tous les cas, le mandant peut agir directement contre la personne que le mandataire s'est substituée.
