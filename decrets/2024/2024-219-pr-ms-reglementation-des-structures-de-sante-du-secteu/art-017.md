# Article 17
Le présent décret s’applique à toutes les structures de santé privées, qu’elles soient mixtes, médicales, chirurgicales et/ou d’accouchement, les laboratoires, les cabinets dentaires etc.
Il fixe notamment, le fonctionnement de ces établissements en ce qui concerne :
– L’Equipement ;
– Le Personnels ;
– Les Catégories de chambres ;
– L’Intendance ;
– Le Contrôle Technique.
