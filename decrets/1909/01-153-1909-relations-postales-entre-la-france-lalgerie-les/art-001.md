# Art. 1er
Dans les relations entre la France, FAlgérie, les colonies françaises, d’une part, les bureaux de poste francais du Maroc et de Tripoli de Barbarie, d’autre part, ainsi que dans les rapports de ces derniers bureaux entre eux, le droit à percevoir sur les mandats de poste ordinaires, sur les mandats de recouvrement el sur les mandals d’’abonnement aux journaux, est calculé d’après le larif intérieur français.
