# Article 3
Il est alloué une indemnité forfaitaire de déplacement de 130 points d’indice pour les enseignants de l’enseignement de base affectés dans la zone 2.
ZONE 2 :
ALI ADDEH, GOUBETTO, HINDI, FARADIL, DAASBYO,HOLL HOLL, OMAR DJAGA,GARSALEDABA, AS-EYLA 1, ASEYLA 2, HANLE, BONDARA , YOBOKI,ABAYTOU, RANDA, ADAILLOU , DAY, , GARANLEH ,DITILLOU, , BOLLI, ADOYLA, OURGANGA, GALINA, KHOR-ANGAR, WADDI, MEDEHO, ASSASSAN, ROURE
