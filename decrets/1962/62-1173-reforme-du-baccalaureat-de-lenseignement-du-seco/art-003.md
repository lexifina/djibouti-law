# Art. 3
— Le diplôme de bachelier de l’enseignement du second degré est délivré par le ministre de l’éducation nationale dans les formes déterminées par les lois et règlements relatifs aux grades d’Etat. Sauf dérogation accordée ou décidée par le recteur, les candidats doivent se présenter dans le département où ils ont accompli le dernier semestre d’études avant l’examen. Ceux qui ne suivent les cours d’aucun établissement se présentent dans le département de leur résidence. Les candidats qui accomplissent leurs études à l’étranger désignent lors de leur inscription le centre où ils choisissent de se présenter.
