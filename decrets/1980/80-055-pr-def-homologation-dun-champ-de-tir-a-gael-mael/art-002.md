# Article 2
Époque de tirs
Les tirs pourront s’exécuter tous les jours sauf le vendredi et les jours fériés de 6H00 à 19H00.
Limite de la zone dangereuse.
La zone dangereuse est délimitée par les points suivants :
A (945 -789) D(920-789)
B (942-800) E(939-793)
C (918-803)
Elle apparaît teintée sur le croquis joint.
